# Contributing

Thanks for checking out SignalForge War Room.

This is a public demo repository designed to show production-style AI-agent engineering patterns using TypeScript, synthetic data, deterministic tools, OpenAI Structured Outputs, validation, tests, docs, and CI.

## Contribution Scope

Good contributions include:

- bug fixes
- clearer documentation
- safer validation logic
- stronger tests
- improved synthetic data quality
- additional deterministic tools
- better CLI output formatting
- non-sensitive example outputs

Please do not contribute:

- private company data
- real customer records
- private prompts
- private repository content
- confidential workflows
- real CRM exports
- API keys or secrets
